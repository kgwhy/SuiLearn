# 随心学 SuiLearn 产品需求文档（初版）

> **本文档为历史讨论记录，不作为实现依据。当前规格以 `docs/product-requirements.md` 为准。**

## 1. 产品定位

随心学 SuiLearn 是一款 Android 学习 App，第一版先做成一个无需登录、开箱即用、能刷题也能主动探索知识的 Java 八股学习工具。

这个产品不是以商业化为第一目标，而是作为一个用 AI 探索产品开发、并且能真正进入日常生活的个人学习工具。

当前最朴素的第一座里程碑是：

> 先做出一个愿意每天打开 5 分钟的 Java 八股刷题 App。

## 2. 方向选择

原始设想有两个方向：

1. 刷题软件：可以接入 RAG，自动生成题，支持不同知识库，例如 Java 八股、英语单词、语文古诗词，并拥有错题本，可以针对薄弱点复习。
2. 小说阅读 App：类似开源阅读，用于看小说，可导入本地 TXT，也可导入网络书源。

最终建议优先选择刷题软件。

原因：

- 刷题软件更适合作为第一款 AI 开发产品。
- 它更能训练产品设计、工程设计和 AI 应用落地能力。
- 刷题、错题、解析、知识点、学习计划、AI 生成题、RAG 检索等模块都适合 AI 辅助开发。
- 小说阅读 App 会涉及网络书源、解析规则、反爬、版权、格式兼容、章节抓取、换源、净化、更新检测等大量琐碎问题。
- 刷题软件更容易做出自己的差异化。

## 3. 初始需求

已经明确的初始需求：

- 开箱即用。
- 无需登录。
- 先从 Java 八股做起。
- 第一版先完成 V0 + V1 + V2：内置题库、刷题闭环、错题复习、本地进度、本地搜索和知识点学习地图。
- 后续再逐步加入 AI 生成题、RAG 知识库、多学习包等能力。

第一版产品定位：

> 一个无需登录、开箱即用的 Java 八股学习 App。先不做复杂社区、账号、云同步，专注“打开就能刷、刷完能复盘、还能主动搜索和补知识点”。

## 4. 第一版范围

第一版包含 V0 + V1 + V2，先聚焦 Java 八股的可用闭环和主动学习能力。

核心功能：

1. 内置 Java 八股题库
2. 刷题模式
3. 简单题型
4. 错题本
5. 本地进度
6. 本地搜索
7. 知识点学习地图

### 4.1 内置 Java 八股题库

第一版先内置 Java 八股相关内容。

建议分类：

- JVM
- 集合
- 并发
- Spring / Spring Boot
- MySQL
- Redis
- 计算机网络
- 操作系统
- 设计模式
- 项目场景题

第一版题库不需要一开始很大，重点是跑通产品闭环。

### 4.2 刷题模式

建议支持：

- 顺序刷题
- 随机刷题
- 按知识点刷题
- 错题重刷

### 4.3 题型

可支持的题型：

- 单选题
- 多选题
- 判断题
- 简答题

第一版优先做：

- 单选题
- 简答题

这样开发成本更低，体验也够用。

### 4.4 错题本

错题本需要支持：

- 自动记录答错题
- 显示正确答案和解析
- 支持标记“已掌握”
- 按知识点统计错题数量

### 4.5 本地进度

本地进度需要支持：

- 无需登录
- 保存做题记录
- 记录正确率
- 记录已刷数量
- 记录连续学习天数

### 4.6 搜索

搜索是第一版的核心能力之一，它让用户不只是被动刷题，也可以主动探索知识。

第一版先做本地关键词搜索。

搜索范围：

- 题干
- 选项
- 答案
- 解析
- 知识点标签
- 分类名

用户可以搜索：

- HashMap
- synchronized
- volatile
- Spring Bean 生命周期
- 索引失效

搜索结果可以展示：

- 匹配到的题目
- 所属分类
- 题目难度
- 是否做过
- 是否答错过
- 进入题目详情或直接练习的入口

如果第一版时间有限，可以先让搜索结果以题目为主，但知识点搜索和知识点聚合仍属于第一版目标。语义搜索和 RAG 问答放到第二版。

## 5. 学习包扩展思路

虽然第一版从 Java 八股开始，但产品不应该只设计成“Java 题库 App”，而应该设计成“学习包 / 题库包 App”。

核心思路：

> 题库引擎通用化，内容包领域化。

也就是说：

- 刷题
- 错题本
- 统计
- 分类
- 解析

这些能力是通用的；Java、英语单词、古诗词只是不同的内容包。

后续扩展英语单词时，可以加入：

- 卡片题：看英文想中文 / 看中文想英文
- 拼写题：根据中文释义拼写英文
- 单选题：从四个中文释义中选正确答案
- 简答题：输入单词或释义

后续扩展路线可以是：

1. 内置 Java 八股学习包，只支持选择题和简答题。
2. 支持多个学习包，仍以内置包为主。
3. 加入英语单词包，新增卡片题和拼写题。
4. 加入用户导入自定义学习包。
5. 接入 AI / RAG，根据知识库自动生成学习包。

## 6. 版本规划

整体产品分为三个大版本：

- 第一版：V0 + V1 + V2，完成 Java 八股本地学习工具。
- 第二版：V3 + V4，加入 AI 辅助和 RAG 知识库。
- 第三版：V5 + V6，扩展到多学科和个人智能学习伙伴。

### V0：概念验证版

目标：

> 证明这个 App 能跑起来，并且用户愿意打开它。

完成内容：

- Android App 基础框架
- 无需登录
- 内置少量 Java 八股题，例如 30 到 50 道
- 能按题目刷题
- 答题后显示答案和解析
- 本地保存简单答题记录

完成标准：

> 能每天打开它刷几道题，并且觉得“这东西确实能帮我复习”。

### V1：可日用刷题版

目标：

> 变成一个真正能用的 Java 八股刷题工具。

完成内容：

- Java 八股分类题库
- 分类刷题
- 随机刷题
- 错题本
- 收藏题
- 做题进度
- 正确率统计
- 本地数据持久化
- 基础搜索：可以搜题干、解析、知识点关键词

这一版形成完整闭环：

> 刷题 -> 答错 -> 进入错题本 -> 复习 -> 统计薄弱点。

完成标准：

> 面试复习 Java 时，可以真实依赖它，而不是把它当 demo。

### V2：主动学习版

目标：

> 不只是被动刷题，而是能主动探索知识。

完成内容：

- 知识点页面
- 搜索知识点
- 每个知识点关联相关题目
- 每道题显示相关知识点
- 薄弱知识点统计
- 错题按知识点聚合
- 支持“我今天想补 volatile / HashMap / Spring Bean 生命周期”这种学习路径

完成标准：

> 当用户突然想查一个 Java 概念时，会先打开这个 App，而不是只去搜索引擎。

### V3：AI 辅助版

目标：

> 开始真正用 AI 提升学习效率，但不急着做复杂 RAG。

完成内容：

- 根据已有知识点生成新题
- 根据错题生成相似题
- 根据某个知识点生成简短解释
- 根据答题情况生成复习建议
- AI 输出内容先经过保存，变成本地题库的一部分
- 支持手动删除或修正 AI 生成的不靠谱内容

完成标准：

> 用户错了某类题之后，App 能帮用户生成几道针对性练习，而不是只告诉用户“你错了”。

### V4：知识库 / RAG 版

目标：

> 把用户自己的资料变成可学习内容。

完成内容：

- 导入本地资料，例如 Markdown、TXT、PDF
- 从资料中提取知识点
- 基于资料生成题目
- 基于资料回答问题
- 搜索从关键词搜索升级为语义搜索
- 可以创建不同知识库，例如 Java 面试、Spring、MySQL、英语单词、古诗词

完成标准：

> 用户丢进去一份学习资料，它能帮用户变成可搜索、可刷题、可复习的内容。

### V5：多学科生活版

目标：

> 从 Java 八股扩展到生活里真正会用的学习场景。

完成内容：

- 支持多个学习包
- Java 八股学习包
- 英语单词学习包
- 古诗词学习包
- 每个学习包有自己的题型和学习方式
- 支持每日复习
- 支持长期记忆曲线，类似简单版 Anki
- 支持跨学科搜索

完成标准：

> 用户不只在准备面试时用它，平时背单词、记知识点、复习资料也会用它。

### V6：个人智能学习伙伴版

目标：

> 让它像一个长期陪用户学习的个人系统。

完成内容：

- 自动总结学习状态
- 自动发现长期薄弱点
- 自动安排复习内容
- 根据错题和搜索记录推荐学习路径
- 支持自然语言提问
- 支持“帮我复习今天学过的内容”
- 支持“根据我最近错题出一套小测”
- 支持本地优先，AI 可选调用

完成标准：

> 它不只是一个 App，而是用户学习时会自然想到的助手。

## 7. 实际开发节奏

建议节奏：

```text
第一版：V0 + V1 + V2
先做成一个真正可用的 Java 八股学习 App，既能刷题复习，也能搜索和补知识点。

第二版：V3 + V4
接入 AI 和 RAG，开始探索 AI 应用的核心能力。

第三版：V5 + V6
扩展到英语、古诗词、个人长期学习系统。
```

最重要的是：

> 不要一开始就冲 V4。

如果一上来就做 RAG、多知识库、AI 生成、多学科，很容易变成“技术很复杂，但自己不用”。

## 8. 产品命名

中文名首选：

> 随心学

原因：

- “随心刷”更像刷题 App，重心在“题”。
- “随心学”更像个人学习工具，能容纳 Java 八股、英语单词、古诗词、搜索探索、错题复习、AI 生成题、RAG 知识库和长期学习计划。
- 产品不是只想让用户机械刷题，而是想让用户主动探索、查漏补缺、把资料变成知识。

副标题可以是：

> 把资料变成练习，把错题变成进步。

或者：

> 一个为自己打造的 AI 学习工具。

英文名建议：

> SuiLearn

中文 / 英文组合：

> 随心学 SuiLearn
> 一个为自己打造的 AI 学习工具。
