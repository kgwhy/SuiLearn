# 优化 Web 导入资料后的内容查看和知识点可读性

## 背景

用户反馈：导入资料后应能查看资料内容，知识点不应只是无法查看的关键词。当前 Web 工作台已有资料详情接口和知识点列表，但资料详情优先展示短预览，导入完成后不会自动打开详情；资料关联知识点在详情区仍以 chip 为主，用户很难直接阅读知识点内容和来源。

## 范围

- Web 端导入资料成功后，自动切到资料区并打开新导入资料详情。
- 资料详情优先展示完整正文；仅在后端未返回正文时回退到 `contentPreview`。
- 知识点在资料详情和总览中以可阅读详情呈现，包含名称、描述、来源资料和来源摘录，不再只作为孤立关键词。
- 补充 Web 端回归测试，防止资料正文和知识点详情退回为不可读标签。

## 非目标

- 不修改后端接口、数据库或 OpenAPI 契约。
- 不改变知识点提取算法。
- 不实现知识点编辑保存流程。
- 不修改 Android 客户端。

## 验收标准

- 用户导入 READY 资料后，页面自动显示该资料详情。
- 资料详情区域可阅读完整 `content`，并清楚标识正文来源；缺少正文时才显示预览。
- 资料关联知识点显示为详情条目，可直接阅读描述和来源摘录。
- `npm --prefix apps/web test` 和 `npm --prefix apps/web run build` 通过。
