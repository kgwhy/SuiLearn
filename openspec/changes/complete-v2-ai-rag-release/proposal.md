# 完成 V2 AI/RAG 发布

## 背景

Reviewer Agent 发现 V2 实现仍有发布缺口：真实 AI Provider 执行路径、已保存 AI 内容进入学习闭环、服务端学习记录、语义检索，以及 Web 工作台测试覆盖不足。本变更用于按当前 V2 范围关闭这些缺口。

## 范围

- 实现真实 OpenAI-compatible Provider 路径，或使用明确批准的适配器回退。
- 将用户保存的 AI 生成题接入正式学习流程。
- 增加后端答题/错题/收藏学习记录和统计；如果服务端不应拥有这些记录，则修订契约。
- 用已批准的语义检索行为替代纯关键词检索。
- 为 Web 的知识库、资料导入、AI 审核、搜索和 RAG 流程增加源码级测试。
- 清理围绕退役 `docs/proposals/**` 引用的工作流/文档漂移。

## 非目标

- 不增加登录、云同步、社区、市场、团队协作或多租户权限。
- 除非另行批准，不增加原始 PDF/OCR/Office 解析。
- 不绕过 AI 内容审核门禁。

## 验收标准

- 真实 AI Provider 状态可以在配置完成后变为可用，且不泄露密钥。
- 用户保存的 AI 生成题可以按已批准架构进行练习、搜索、复盘、收藏和统计。
- 后端知识库统计来自持久化答题记录。
- 搜索行为符合已批准的语义搜索契约。
- Web 自动化测试覆盖 V2 工作台重流程。
- 稳定当前事实文档不再把新变更指向退役 proposal 目录。
