# 分支与发布

仅在创建或切换分支、提交后拉取、推送或处理冲突时读取本文件。

## 分支

- 创建 Codex 分支时默认使用 `codex/` 前缀，除非用户指定其他名称。
- 切换或创建分支前先检查 `git status --short --branch`，不覆盖用户已有变更。

## 发布顺序

提交已通过提交前预检后，只有用户明确要求发布时才执行：

```powershell
git pull --rebase
git push -u origin <branch>
```

若拉取产生冲突，停止后检查冲突文件；只解决本次已提交工作相关的冲突，重新运行相关检查，并在 rebase 完整结束后再继续。未经明确授权，不使用强制推送或改写历史。
