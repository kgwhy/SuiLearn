# 提交信息

仅在需要创建提交、拟定提交说明或拆分提交时读取本文件；需要选择提交类型或破坏性变更格式时，按 `SKILL.md` 的路由读取 Conventional Commits 参考。

## 原则

- 标题使用 Conventional Commits，说明文字使用中文。
- 按职责拆分无关改动；用户要求单次提交且文件边界一致时可合并。
- 正文不是默认必填项。标题足以表达改动时可只提交标题；需要补充时使用简短的“变更摘要”。

## 默认模板

```text
<type>[optional scope][optional !]: <中文说明>

变更摘要：
- <主要改动>
```

不要在提交正文模板中加入验证结果、风险说明或无关的填充文字。这些信息如有必要，应在交接报告中单独说明。

## 示例

```text
fix(auth): 拒绝过期访问令牌
```

```text
refactor(git): 拆分提交前预检流程

变更摘要：
- 将安全扫描与提交信息指引分离
```
