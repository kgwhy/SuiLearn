# UI 证据

用户可见 UI 变更必须附证据。

## 必须

- 从本次 tree 的真实构建启动应用。
- 使用真实后端/真实数据流；任何 mock、fixture 或测试钩子都要在证据旁声明。
- 记录 commit SHA、启动命令、运行条件（浏览器/设备、后端来源、是否真实模型）。
- 至少 3-6 个语义状态截图或一段录屏：初始、输入、运行中、完成/失败、详情。
- 截图或视频/GIF 不提交进主分支历史；放 assets 分支或外部对象存储。

## 禁止

- 用延迟 sleep 代替具体 UI 条件。
- 用 mock 数据冒充真实流程。
- 把不同运行轮次的帧拼成一段演示。
- 截图中出现凭据、个人数据或无关窗口。

## 自审

完成门禁和 Reviewer 自审时，缺 UI 证据按 P1 处理。
